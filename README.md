# planleaf

Plan and reshape leaf text streams with deterministic transforms.

**Site:** https://theworker02.github.io/planleaf/

## Install / run

```bash
git clone https://github.com/theworker02/planleaf.git
cd planleaf
node src/cli.js
node --test
```
